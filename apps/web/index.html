From directory to dialogue.

Open your terminal. Bring a file. Start a convo.

  1. 01

    Meet Convo in your directory

    Move into the folder with your files, then launch Convo.

    $ cd ~/Documents
    $ convo

    Or browse another folder with convo --directory ~/Documents. First launch prepares your local database.

  2. 02

    Connect. Pick a file.

    Use /login to connect your ChatGPT account in the browser. Then use /file to select and index a file.

    /login→/models→/file

    Choose your model with /models. The first file downloads the local embedding and reranking models.

  3. 03

    Ask away. Follow the sources.

    Type a question and press Enter. Read the answer alongside quotations from your selected file.

    › What are the key ideas in this document?

    Conversations save automatically. Pick up where you left off with /sessions.

A few commands.
A lot less friction.

Type / in Convo to see suggestions.

/login
Connect your ChatGPT account
/file
Choose and index a file
/models
Search and choose a model
/thinking
Choose the thinking effort
/help
See all commands and keys
/quit
Close Convo
/sessions
Find and resume saved chats
/new
New chat, same selected file
/clear
Same as /new; keeps old chats
/reset
New chat without a file
/sessions <uuid>
Resume a chat directly by ID
Ctrl+O
Open the file picker
Ctrl+T / Shift+Tab
Cycle supported thinking levels
F2
Pick a thinking level directly
PageUp / PageDown
Scroll the conversation
Esc
Cancel file preparation
Ctrl+C
Exit Convo

↳ In the command menu: ↑ ↓ to navigate, Tab to complete.

What files can I bring? +

TXT, Markdown, PDF, DOCX, CSV, JSON, Python, RST, and log files. Up to 10 MB per file, with a limit of 500,000 extracted characters and 2,000 chunks.

Files are indexed locally. Relevant passages go to your connected ChatGPT account to generate an answer.
